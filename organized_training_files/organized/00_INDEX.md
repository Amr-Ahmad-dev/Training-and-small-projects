# Index — Organized Training Files

All original code/notebook/data files are copied **unmodified** into the folders
below. Nothing inside any `.py`, `.ipynb`, `.xlsx`, or `.csv` file was changed —
only a `README.md` was added per folder to describe what that code trained on and
what problem it solves. See each folder's `README.md` for full per-file detail.

| Folder | Theme | Data trained on |
|---|---|---|
| `01_Python_Fundamentals_Practice/` | Core Python drills: loops, functions, classes, lambdas | Inline lists/strings/dicts (no external file) |
| `02_Student_Management_System/` | CLI app for managing students & courses | User-entered data, kept in memory |
| `03_Data_Preprocessing_and_Visualization/` | Cleaning, feature engineering, EDA, plotting | `students_dataset.xlsx` (gradebook) and seaborn's `tips` dataset |
| `04_Machine_Learning_Titanic/` | Binary classification with logistic regression | Titanic dataset (two different sources/versions) |
