## 📌 Overview

This repository serves as an organized workspace and learning roadmap covering core Python development, object-oriented program design, hands-on **data analytics/visualization**, and practical **machine learning classification**.

The repository is organized into four core progression stages:

1. **Core Python Drills:** Control flow, functions, lambdas, and object-oriented programming (OOP).
2. **Software Systems:** Interactive command-line interface (CLI) tools and in-memory state management.
3. **Data Engineering & EDA:** Data cleaning, missing value imputation, feature transformation, and exploratory visualization.
4. **Machine Learning:** Binary classification pipelines using Logistic Regression and performance evaluation.
